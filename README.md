# Mushfick Jahan Mojahid — Portfolio Website

A responsive personal + professional-style portfolio starter built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code with Live Server.
3. `profile-photo.png` is the provided portrait photo used in the hero and gallery.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling and illustrations
- `script.js` — mobile menu and scroll reveal
- `profile-photo.png` — supplied profile photo

## Before publishing
- Confirm the profile details and obtain the owner's approval to publish their photo and information.
- The available information only supports the displayed location, hometown, educational institution, and interests. No job title, professional skills, work history, email, or phone number has been invented.
- Replace gallery placeholders only with images approved by the owner.
- Facebook profile link is included as the contact action.
